# Burger House

Site responsive pour un restaurant de burgers.

## Fonctionnalités

- Page d'accueil moderne et responsive
- Menu filtrable par catégorie
- Panier interactif avec quantités
- Panier sauvegardé dans le `localStorage`
- Formulaire de contact
- Navigation mobile
- Compatible avec les navigateurs modernes

## Utilisation

Ouvrez simplement `index.html` dans un navigateur. Aucun serveur ou installation n'est nécessaire.

Les images du burger sont réalisées en CSS et les illustrations des produits utilisent des emojis afin de garder le projet léger et autonome.

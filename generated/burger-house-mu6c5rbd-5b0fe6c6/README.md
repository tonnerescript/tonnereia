# Burger House

Site moderne et responsive pour un restaurant de burgers.

## Fonctionnalités

- Page d'accueil avec présentation du restaurant
- Menu filtrable par catégorie
- Ajout et retrait de produits dans un panier
- Panier sauvegardé dans le navigateur avec `localStorage`
- Formulaire de contact avec message de confirmation
- Navigation responsive adaptée aux mobiles

## Lancement

Aucune installation n'est nécessaire. Ouvrez simplement `index.html` dans un navigateur récent.

Pour un meilleur résultat, lancez le projet avec un serveur local, par exemple avec l'extension Live Server de VS Code ou avec cette commande :

```bash
npx serve .
```

Les polices sont chargées depuis Google Fonts lorsque la connexion Internet est disponible.

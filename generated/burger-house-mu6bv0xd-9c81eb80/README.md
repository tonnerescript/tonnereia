# Burger House

Site responsive pour un restaurant de burgers.

## Fonctionnalités

- Page d'accueil moderne et adaptée aux mobiles
- Menu filtrable par catégorie
- Ajout et suppression de produits dans un panier dynamique
- Panier sauvegardé dans le navigateur avec `localStorage`
- Formulaire de contact avec validation HTML
- Navigation mobile responsive

## Lancement

Aucune installation n'est nécessaire. Ouvrez simplement `index.html` dans un navigateur web.

Pour un meilleur résultat, lancez le projet avec un serveur local, par exemple avec l'extension Live Server de VS Code.

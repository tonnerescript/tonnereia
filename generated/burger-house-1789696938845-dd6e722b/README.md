# Burger House

Site responsive pour un restaurant de burgers.

## Fonctionnalités

- Page d'accueil avec présentation du restaurant
- Menu filtrable par catégorie
- Panier interactif sauvegardé dans le navigateur
- Formulaire de contact avec confirmation
- Navigation mobile
- Design adapté aux smartphones, tablettes et ordinateurs

## Utilisation

Ouvrez simplement `index.html` dans un navigateur. Aucun serveur ni installation n'est nécessaire.

Les images sont chargées depuis Unsplash. Le paiement et l'envoi réel du formulaire sont volontairement simulés côté frontend.
